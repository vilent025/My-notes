## 一、练习步骤（固定流程）

1. 先通读原文：看懂中文主干，圈出名词、动词、数字、中国特色词；不要逐字硬翻。
2. 自己动笔写译文（限时，10 分钟 / 段），不查词典。
3. 对照参考译文：
   - 标出你和标准答案不一样的地方，区分：**语法错误 / 选词问题 / 句式优劣**
   - 摘抄固定表达（传统文化、经济、社会、历史类短语）
4. 回译：盖住中文，看英文翻译回中文，检查逻辑是否通顺。
5. 跟读朗读**：读译文，熟悉英文语序，避免中式英语。

## 二、高频考点分类（四级翻译几乎只考这 4 类）

1. 传统文化：节日、建筑、书法、中医、四大发明、瓷器、剪纸、茶道
2. 历史地理：名山河流、古都、省份、历史朝代
3. 社会发展：交通、互联网、教育、旅游、乡村发展
4. 经济民生：农产品、制造业、消费


> 核心句型储备：被动语态；定语从句；分词作状语；it 作形式主语；there be；倍数表达。

## 三、每日训练量建议

- 基础一般：1 篇 / 天（140–160 汉字），精做＞刷量
- 基础较好：2 篇 / 天，一篇精翻，一篇限时模考

## 四、避坑要点

1. 不要堆砌难词！四级翻译优先保证**语法正确**，简单准确的词汇得分更高。
2. 中文多短句，英文要适当合并，不要一句中文对应一句英文。
3. 专有名词记标准译法，不要自创（如故宫 the Palace Museum）。
4. 时态：介绍事物概况用一般现在时；讲古代历史用一般过去时。
