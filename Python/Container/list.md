"""
列表的定义
1.字变量
[元素1，元素2,...]
2.定义变量
变量名称 = [元素1，元素2，...]
3.定义空列表
变量名称 = []
变量名称 = list()

列表的元素类型不受限制

列表里可以嵌套列表

可以通过下标取出对应元素（第一个元素的下标是0）
    可以反向索引（从后向前）：从-1开始，依次递减（-1，-2，-3，...）
"""

"""
列表的常用操作（方法）：
查找某元素的下标：
    list.index(ele)

修改索引的元素值：
    list[index] = newele
    
插入元素：
    list.insert(index,ele)

追加元素(元素加到列表的尾部)：
    1.list.append(ele)
    2.list1.expend(list2)
    
删除元素：
    1.del list[index]
    2.list.pop(index)  #可用变量接收删除的值

删除列表的某元素：
    list.remove(ele1)  #清除list里面第一个的ele1
    
清空列表：
    list.clear()    
    
统计列表中某元素的数量：
    list.count(ele1)  #统计ele1的数量  
    
统计列表中所有元素
    len(list)
"""
